# 한양대 공지 → 텔레그램 자동 알림

한양대 전체공지와 경영대 공지에 새 글이 올라오면, 정해진 시각마다 확인해 **텔레그램으로 자동 전송**하는 시스템입니다.

- **기간**: 2026.06 (약 1주) · 개인 프로젝트
- **역할**: 문제 정의, 기술 의사결정, 배포, 디버깅
- **기술**: Python (feedparser, requests) · GitHub Actions (cron) · Telegram Bot API
- **AI 활용**: 생성형 AI(Claude)를 개발 파트너로 활용

---

## 1. 왜 만들었나

학교·경영대 공지를 매번 사이트에 들어가 직접 확인해야 했고, 중요한 공지를 놓치는 일이 생겼습니다.
새 공지만 골라 휴대폰으로 받아 볼 수 있도록 직접 만들었습니다.

## 2. 동작 방식

```
[GitHub Actions 예약 실행]
        │
        ▼
[RSS 수집] 전체공지 · 경영대 공지
        │
        ▼
[새 글 선별] seen.json('읽음' 기록)과 비교해 처음 보는 글만 남김
        │
        ▼
[텔레그램 전송] 제목 + 링크
        │
        ▼
[읽음 기록 저장] seen.json 업데이트 → 다음 실행 때 중복 발송 방지
```

## 3. 기술 의사결정

| 항목 | 검토 | 선택 | 이유 |
|---|---|---|---|
| 알림 채널 | 카카오톡 | **텔레그램** | 카카오톡은 토큰이 수 시간 만에 만료되고 약 2개월마다 재인증이 필요해 유지 부담이 큼. 텔레그램 봇 토큰은 영구적 |
| 수집 방식 | HTML 크롤링 | **RSS** | 크롤링은 사이트 구조가 바뀌면 깨짐. RSS는 구조 변화에 영향을 받지 않아 안정적 |
| 실행 환경 | 개인 PC | **GitHub Actions** | PC가 꺼지면 멈춤. GitHub Actions는 클라우드에서 상시 예약 실행 가능 |

## 4. 안정성 설계

- **중복 발송 방지**: 보낸 공지를 `seen.json`에 '읽음'으로 기록
- **첫 실행 예외 처리**: 처음 실행할 때 기존 글을 한꺼번에 보내지 않고 '읽음'으로만 기록
- **자가 진단**: RSS 수집에 실패하면 텔레그램으로 스스로 경고 전송
- **보안**: 텔레그램 토큰과 CHAT_ID는 코드에 쓰지 않고 GitHub Secrets에 보관

## 5. 디버깅 기록

**① 배포 후 `exit code 1` 오류**
- 실행 로그를 열어 원인을 라이브러리 설치 단계로 좁힘
- 설정 파일을 인식하지 못하는 문제임을 확인
- 파일을 다시 만들어도 반복되어, 파일 의존 자체를 없애는 방식으로 해결

**② 자동 실행이 동작하지 않음**
- '자동 실행 기록이 없다'는 점을 근거로, 무료 스케줄러의 지연·누락 특성 때문이라고 진단
- 실행 주기를 정시 기반으로 다시 설계해 안정화

## 6. AI 활용 방식

AI에 질문하고 답을 받는 데서 그치지 않고, 다음 과정을 반복했습니다.

1. 요구사항 제시: 무엇을, 어떤 조건으로 받고 싶은지 정의
2. 구조 설계: 알림 채널·수집 방식·실행 환경을 AI와 함께 비교하고 직접 결정
3. 실행·검증: AI가 만든 코드를 실제 클라우드에 올려 실행
4. 반복 개선: 오류 로그를 근거로 원인을 가설로 세우고, 수정 방향을 AI에 요청

## 7. 파일 구성

```
├─ check_notices.py            # RSS 수집, 새 글 선별, 텔레그램 전송
├─ requirements.txt            # 필요한 라이브러리
├─ seen.json                   # 이미 보낸 공지 기록 (자동 업데이트)
└─ .github/workflows/
   └─ notices.yml              # 예약 실행 설정 (cron)
```

## 8. 직접 설치하려면 (요약)

1. 텔레그램 @BotFather에서 봇을 만들고 토큰 받기
2. 만든 봇에게 메시지를 한 번 보낸 뒤, @userinfobot에서 CHAT_ID 확인
3. 이 저장소의 파일을 내 저장소에 올리기
4. `check_notices.py`의 FEEDS에 공지 게시판 RSS 주소 넣기
5. Settings → Secrets and variables → Actions에 `TELEGRAM_TOKEN`, `CHAT_ID` 등록
6. Actions 탭에서 Run workflow로 한 번 실행해 확인
